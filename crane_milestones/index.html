    Crane Pipeline Milestones

    Running log of architectural/skill milestones in this repo, for REVIEW mode (see AGENTS.md) to compare current work against. Not a full changelog — only entries that mark a real shift in approach (new pattern, new tooling, new discipline), so progress over months is visible at a glance.

    How this file grows

    After each REVIEW, append one new row: date, commit hash (or "WIP tip" if uncommitted), a short milestone label, and a one-line note on what it demonstrates skill-wise. Keep entries to real shifts in approach, not every commit — this file is meant to stay short enough to read in one pass years from now.
